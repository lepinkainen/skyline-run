# Skyline//Run

A one-button neon cyberpunk rooftop endless runner, built with Phaser 4, TypeScript and Vite.

**▶ Play it: https://lepinkainen.github.io/skyline-run/**

## Development

```sh
npm install
npm run dev     # dev server
npm run build   # type-check + production build into dist/
```

Pushes to `main` are deployed to GitHub Pages by `.github/workflows/deploy.yml`.
